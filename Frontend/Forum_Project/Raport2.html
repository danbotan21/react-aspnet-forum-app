1. Introducere

Prezentul raport documentează implementarea componentelor de creare conținut pentru aplicația forum. Aceste pagini permit utilizatorilor să fondeze noi comunități și să compună postări cu suport pentru multiple tipuri de conținut.

Raportul se concentrează pe două pagini critice: Start Community (management comunități) și Create Post (creare postări avansată cu drag-and-drop). Ambele demonstrează gestionare avansată a formularnelor, validare input-uri și interacțiuni complexe.

2. Pagina Start Community - Creare Comunități

2.1 Descriere și Scop

Pagina Start Community (StartCommunity.jsx) oferă o interfață formular pentru crearea noilor comunități. Aceasta ghidează utilizatorii printr-o secvență logică: selectare categorie, introducere detalii, upload imagine și selectare tip confidențialitate.

2.2 Componentă 1: Selectare Categorie

Utilizatorii aleg dintr-o colecție de 8 categorii predefinite prin intermediul chip buttons interactivi:

  • Gaming
  • Technology
  • Art
  • Music
  • Sports
  • Education
  • Travel
  • Food

Categoria default selectată este "Technology". Fiecare buton include atributul aria-pressed pentru accesibilitate. Stare gestionată prin selectedCategory.

2.3 Componentă 2: Detalii Comunitate

Utilizatorii introduc informații de bază ale comunității prin doua câmpuri:

  • Titlu: Input text cu placeholder "Enter community title". Gestionat prin state communityTitle.
  • Descriere: Textarea pe 5 rânduri cu placeholder descriptiv. Permite utilizatorului să detalieze scopul și valorile comunității. Gestionat prin communityDescription.

2.4 Componentă 3: Upload Imagine

Component upload permet selectarea unei imagini comunității. Implementare include:

  • Icon visual: FaCloudUploadAlt pentru identificare ușoară
  • File input: Accept filter 'image/*' pentru validare
  • Validare clientă: file.type.startsWith('image/')
  • Feedback utilizator: Afișare nume fișier selectat
  • State management: selectedImageName

Funcția handleImageChange validează tipul fișierului și resetează starea dacă nu este imagine validă.

2.5 Componentă 4: Tip Comunitate (Confidențialitate)

Utilizatorul selectează nivelul de confidențialitate din trei opțiuni:

  1. Public: "Oricine poate vedea, posta și comenta." Maximum participație, no moderație.
  2. Restricted: "Oricine poate vedea, dar doar utilizatori aprobați pot posta." Control moderație cu viewing deschis.
  3. Private: "Doar utilizatori aprobați pot vedea și participa." Maximum confidențialitate și exclusivitate.

Type default selectat este "public". Gestionat prin state selectedType.

2.6 Fișier CSS Asociat

Stilizarea este definită în StartCommunity.css:

  • .start-community-page - Container principal
  • .start-community-card - Card formular
  • .start-community-chip - Category buttons
  • .start-community-chip--active - Stare selectată
  • .start-community-input, .start-community-textarea - Form fields
  • .start-community-upload - Upload zone
  • .start-community-type-btn - Privacy buttons

3. Pagina Create Post - Creare Postări Avansată

3.1 Descriere Generală

Pagina Create Post (CreatePost.jsx) este cea mai complexă componentă din raport. Oferă o interfață editor taburi cu suport pentru trei tipuri de conținut: text, imagini și linkuri. Implementează drag-and-drop avansat, management scheme (drafts), și gestionare avansată a memoriei.

3.2 Secțiune Header

La deschidere, componenta afișează:

  • Eyebrow label: "Community publishing"
  • Titlu: "Create a Post"
  • Subtitle: Descriere scop și funcționalitate
  • Drafts button: Buton baston cu counter "Drafts 2" indicând 2 scheme salvate

3.3 Selector Comunitate

Un input search permite utilizatorului să selecteze comunitatea destinație post:

  • Icon: FaSearch pentru identificare vizuală
  • Placeholder: "Choose a community"
  • State: community
  • Funcționalitate: Search filtering comunități disponibile

3.4 Editor Taburi Multi-Tip

Componenta implementează un sistem de taburi cu trei opțiuni:

3.4.1 TAB TEXT (Default)

Pentru postări text tradiționale:

  • Input Titlu: Obligatoriu, placeholder "Title"
  • Textarea Corp: 10 rânduri, placeholder "Text (optional)"
  • State: postTitle, postBody
  • Clase CSS: create-post-title-input, create-post-body-input

3.4.2 TAB IMAGES (Drag & Drop Avansat)

Pentru postări cu imagini - cea mai complexă componentă:

  • Drag & Drop Zone: Aria prin care utilizator poate glisa imagine
    Implementare: handleDragEnter, handleDragLeave, handleDragOver, handleDrop
  • Visual Feedback: Clasa CSS "drag-active" schimbă styling zona când fișier este peste ea
  • Drag Counter (dragCounterRef): Previne false triggers la nested elements
    Incrementează la dragEnter, decrementează la dragLeave
  • Click-to-Upload Fallback: Buton FaCloudUploadAlt pentru compatibilitate
    Deschide file picker: fileInputRef.current?.click()
  • Validare Fișier: Controlează MIME type cu file.type.startsWith('image/')
    Afișează error: "Please choose an image file."

3.4.3 Preview Imagine și Memory Management

După selecție imagine:

  • URL.createObjectURL(): Crează URL blob pentru preview instant
    setPreviewUrl(URL.createObjectURL(file))
  • URL.revokeObjectURL(): Cleanup mandatory la schimbare sau unmount
    Previne memory leaks: URL.revokeObjectURL(previewUrl)
  • useEffect Cleanup: Revoke URL-uri rămase la component unmount
    Essential pentru single page applications

3.4.4 TAB LINK

Pentru postări cu linkuri externe:

  • Textarea URL: 2 rânduri, placeholder "URL"
  • State: postUrl
  • Funcționalitate: Simpla, pentru partajare linkuri externe

3.5 Butoane Acțiuni

  • Save Draft: Salvează post ca schemă (state persisted)
  • Post: Publică post în comunitate selectată

4. Pattern-uri Avansate și Best Practices

4.1 Drag and Drop Implementation

const handleDragEnter = useCallback((e) => {
  e.preventDefault()
  if (e.dataTransfer?.items?.length) {
    dragCounterRef.current += 1
    setDragActive(true)
  }
}, [])

const handleDrop = useCallback((e) => {
  e.preventDefault()
  dragCounterRef.current = 0
  setDragActive(false)
  if (e.dataTransfer.files?.[0]) {
    handleFile(e.dataTransfer.files[0])
  }
}, [handleFile])

4.2 Memory Management cu URL.createObjectURL

const handleFile = useCallback((file) => {
  if (previewUrl) URL.revokeObjectURL(previewUrl) // Cleanup vechi
  setPreviewUrl(URL.createObjectURL(file))
}, [previewUrl])

useEffect(() => {
  return () => {
    if (previewUrl) URL.revokeObjectURL(previewUrl) // Cleanup mount
  }
}, [previewUrl])

4.3 Modal cu ESC Key Support

useEffect(() => {
  if (!isDraftsOpen) return

  const handleEscape = (e) => {
    if (e.key === 'Escape') setIsDraftsOpen(false)
  }

  document.addEventListener('keydown', handleEscape)
  const previousOverflow = document.body.style.overflow
  document.body.style.overflow = 'hidden'

  return () => {
    document.removeEventListener('keydown', handleEscape)
    document.body.style.overflow = previousOverflow
  }
}, [isDraftsOpen])

4.4 File Validation și Error Handling

Ambele pagini implementează validare robustă:

  • Type checking: file.type.startsWith('image/')
  • Input validation: Placeholder-uri clare, validare frontend
  • User feedback: Error messages în state, afișare conditată
  • Graceful degradation: Fallback click-upload dacă drag fail
